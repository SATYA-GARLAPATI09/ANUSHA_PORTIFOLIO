## 🌟 Overview
This repository contains the bonafide **Student Portfolio Website** front-end project and documentation developed by **Sankabathula Lakshmi Anusha** during her Web Development short-term internship.

The project demonstrates:
- **Semantic HTML5:** Accessible layout (`<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<form>`, `<footer>`).
- **Modern CSS3:** Fluid typography, CSS custom properties (`:root`), Flexbox navigation, CSS Grid responsive card layouts, and mobile-first media queries.
- **Client-Side JavaScript (ES6):** Real-time dual-state form input validation, regex email verification, mobile navigation drawer toggle, scroll-spy active link tracking, and diagnostic console reporting.
- **Dynamic Profile Photo Upload & Persistence:** In-browser custom photo upload via `FileReader` and `localStorage`, with support for permanent global deployment on Vercel via `portfolio-website/images/profile.jpg`.

## 🚀 Running Locally
1. Clone the repository:
   ```bash
   git clone https://github.com/SATYA-GARLAPATI09/ANUSHA_PORTIFOLIO.git
   ```
2. Double-click `open-portfolio.bat` or open `portfolio-website/index.html` directly in any web browser (Chrome, Edge, Firefox).

---

## 🌐 Deploying to Vercel
1. Import this repository in [Vercel](https://vercel.com).
2. The included `vercel.json` automatically routes traffic to the portfolio website.
3. Click **Deploy**. Your site is instantly live on a custom `.vercel.app` domain!
