## 📷 How to Add Your Real Profile Photo (Visible on Vercel)

There are two seamless ways to add your profile photo:

### Method 1: Permanent Global Photo for Vercel Deployment (Recommended)
1. Take your real passport/profile photo.
2. Rename your photo file to `profile.jpg` (or `profile.png`).
3. Place it into the `images/` directory:
   ```text
   portfolio-website/images/profile.jpg
   ```
4. When deployed to Vercel, every visitor on any phone, tablet, or desktop across the world will automatically see your photo!

### Method 2: Instant In-Browser Upload
1. Open the website in your browser.
2. Click the **📷 Change Photo** button (or the camera badge on your profile avatar).
3. Select your image from your device.
4. The photo updates instantly and is saved in your browser's local storage.

## 🚀 How to Deploy to Vercel

### Option A: Using Vercel Web Dashboard (Easiest)
1. Push this project folder to your GitHub repository.
2. Go to [https://vercel.com](https://vercel.com) and log in.
3. Click **Add New Project** $\rightarrow$ **Import Git Repository**.
4. Set the Root Directory to `portfolio-website` (or leave default if deploying root).
5. Click **Deploy**. Your portfolio will be live at `https://anusha-portfolio.vercel.app`!

### Option B: Using Vercel CLI
```bash
npm install -g vercel
cd portfolio-website
vercel
```
